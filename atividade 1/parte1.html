Sobre a disciplina

A disciplina de estrutura de dados introduz conceitos de métodos de ordenação, complexidade de algoritmos e, principalmente, estruturas de dados famosas em C++, tais como:

  • Vector
  • List
  • Queue
  • Stack
  • Heap (priority queue)
  • Set
  • Map
  • Hash Table
